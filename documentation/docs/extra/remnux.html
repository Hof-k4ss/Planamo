🦠 REMnux

Conteneur Docker spécialisé pour l'analyse de malwares

Présentation

REMnux est une distribution Linux dédiée à l'analyse de malwares. Dans PLANAMO, elle est disponible sous forme de conteneur Docker basé sur l'image officielle remnux/remnux-distro:noble. Elle regroupe des dizaines d'outils d'analyse statique et dynamique : décompilateurs, éditeurs hex, analyseurs de documents, outils réseau, etc.

Lancer REMnux

Ouvrez un terminal et lancez simplement :

remnux

Cette commande démarre un shell interactif dans le conteneur. Un répertoire partagé est automatiquement monté pour échanger des fichiers entre PLANAMO et REMnux.

Répertoire partagé

Vos fichiers à analyser doivent être placés dans le dossier ~/remnux-workdir/ sur PLANAMO. Ce dossier est monté dans le conteneur à l'emplacement /home/remnux/files/.

# Sur PLANAMO — copier un fichier vers REMnux cp /chemin/vers/malware.exe ~/remnux-workdir/ # Dans le conteneur REMnux — analyser le fichier file /home/remnux/files/malware.exe strings /home/remnux/files/malware.exe | head -50
Astuce : Tout fichier créé dans /home/remnux/files/ depuis le conteneur sera visible dans ~/remnux-workdir/ sur PLANAMO, et vice versa.

Prérequis

REMnux nécessite que les images Docker soient chargées. En mode live (ISO) :

# Charger les images Docker depuis l'ISO sudo planamo-docker-load

En mode installé, les images sont chargées automatiquement au premier démarrage.

Exemples d'utilisation courante

# Identifier le type d'un fichier suspect file /home/remnux/files/suspect.bin # Extraire les chaînes lisibles strings -n 6 /home/remnux/files/suspect.bin | grep -iE "(http|cmd|powershell|exec)" # Scanner avec Yara yara /usr/share/yara-rules/index.yar /home/remnux/files/suspect.bin # Analyser un document Office malveillant olevba /home/remnux/files/document.doc # Analyser un PDF suspect pdfid /home/remnux/files/document.pdf pdf-parser --search "/JS" /home/remnux/files/document.pdf

Quitter REMnux

# Quitter le conteneur (le conteneur est supprimé automatiquement) exit
