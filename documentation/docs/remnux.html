Introduction

REMnux est une distribution Linux spécialisée dans l'analyse de malwares, intégrée à PLANAMO sous forme de conteneur Docker. Elle regroupe des centaines d'outils forensiques préconfigurés pour l'analyse statique, dynamique, réseau et documentaire.

Sur PLANAMO, REMnux est disponible hors ligne — l'image Docker est préchargée dans /opt/planamo/docker/.
REMnux s'exécute en conteneur éphémère. Toute modification à l'intérieur sera perdue à la fermeture. Utilisez le répertoire partagé pour persister vos fichiers.

Lancer REMnux via Docker

Méthode rapide — wrapper PLANAMO

Le wrapper remnux lance automatiquement le conteneur avec votre répertoire de travail partagé :

remnux

Cela crée le dossier ~/remnux-workdir/ sur votre machine et le monte dans le conteneur sous /home/remnux/files/. Placez vos fichiers à analyser dans ce dossier.

Lancement manuel

# Shell interactif simple
docker run --rm -it -u remnux remnux/remnux-distro:noble bash
# Avec répertoire partagé
docker run --rm -it -u remnux -v ~/workdir:/home/remnux/files remnux/remnux-distro:noble bash
# Conteneur persistant en arrière-plan (SSH sur port 22)
docker run -d -p 22:22 remnux/remnux-distro:noble

Options Docker utiles

OptionDescription
--rmSupprime le conteneur à la fermeture
-itMode interactif avec TTY
-u remnuxLance en tant qu'utilisateur remnux
-v src:dstMonte un répertoire local dans le conteneur
-dMode détaché (arrière-plan)
-p 22:22Expose le port SSH

Modes d'utilisation

Mode analyse rapide (éphémère)

Pour analyser un fichier rapidement sans garder le conteneur :

docker run --rm -it -u remnux -v ~/workdir:/home/remnux/files remnux/remnux-distro:noble bash

Mode session persistante

Pour conserver les modifications entre les sessions :

# Créer le conteneur sans --rm
docker run -it -u remnux -v ~/workdir:/home/remnux/files --name remnux-lab remnux/remnux-distro:noble bash

# Reprendre la session plus tard
docker start -ai remnux-lab

Analyser des propriétés statiques

Ces outils permettent d'examiner un fichier sans l'exécuter.

file — Identifier le type de fichier

Détecte le type réel d'un fichier indépendamment de son extension.

file malware.bin

strings — Extraire les chaînes lisibles

Affiche les chaînes ASCII et Unicode d'un binaire.

strings -a -n 8 malware.exe | less

exiftool — Métadonnées

Extrait les métadonnées de tout type de fichier.

exiftool document.pdf

pecheck / pescanner — Analyse PE

Analyse les fichiers exécutables Windows (PE).

pecheck malware.exe

ssdeep — Hash flou (fuzzy hashing)

Génère un hash flou pour comparer des fichiers similaires.

ssdeep malware.exe
ssdeep -m known_hashes.txt malware.exe

yara — Détection par règles

Scanne un fichier avec des règles YARA.

yara -r /path/to/rules.yar malware.bin

Analyser du code malveillant

uncompyle6 / decompile3 — Décompiler Python

Reconstruit le code source Python depuis un fichier .pyc

uncompyle6 malware.pyc

js-beautify — Déobfusquer JavaScript

Reformate et rend lisible du JavaScript obfusqué.

js-beautify -o clean.js malware.js

vmonkey — Analyser macros VBA

Extrait et analyse les macros VBA de documents Office.

vmonkey document.doc

oledump — Analyser fichiers OLE

Inspecte les flux OLE dans les documents Office.

oledump.py malicious.doc
oledump.py -s 3 -v malicious.doc

Explorer les interactions réseau

Wireshark / tshark — Analyser des captures réseau

tshark -r capture.pcap -Y "http" -T fields -e http.request.uri

netsed — Modifier le trafic réseau

Intercepte et modifie les paquets réseau en temps réel.

netsed tcp 9999 0 8080 's/evil.com/localhost/g'

Thug — Honeyclient web

Simule un navigateur pour analyser des URLs suspectes.

docker run --rm -it --entrypoint "/bin/bash" remnux/thug
# Puis dans le conteneur :
thug -F http://suspicious-url.com

Analyser des documents

pdfid / pdf-parser — Analyser PDF

pdfid malicious.pdf
pdf-parser -a malicious.pdf

peepdf — Analyse approfondie PDF

peepdf -i malicious.pdf

oletools — Suite Office

oleid malicious.doc
olevba malicious.doc
rtfobj malicious.rtf

Workflow type PLANAMO + REMnux

Exemple d'analyse d'un APK ou binaire suspect :

1. Préparer le répertoire de travail

mkdir -p ~/remnux-workdir
cp /chemin/vers/malware.apk ~/remnux-workdir/

2. Lancer REMnux

remnux

3. Dans le conteneur — analyse statique

cd /home/remnux/files
file malware.apk
strings -a -n 8 malware.apk | grep -i "http\|url\|api\|key"
ssdeep malware.apk

4. Identifier les IOCs réseau

strings malware.apk | grep -E "([0-9]{1,3}\.){3}[0-9]{1,3}|https?://"

5. Scan YARA

yara -r /usr/share/yara-rules/ malware.apk 2>/dev/null
Les résultats dans /home/remnux/files/ sont automatiquement disponibles dans ~/remnux-workdir/ sur PLANAMO.
